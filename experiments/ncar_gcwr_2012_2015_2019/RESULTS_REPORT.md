## 方法与修复

1. 月度链路：NCAR THREDDS NCSS → RDH（SHA-256/NetCDF 校验与断点）→ DBAS → 月度水物质场。
2. 垂直积分：按层厚和地面气压屏蔽地下层；37 层完整覆盖，不把缺测或地下层当作零。
3. 边界通量：按四侧边界和顶层分别分解输入/输出；正 omega 的顶层输入符号已由回归测试固定。
4. 年度更新周期：使用逐月库存日均值按月份天数加权，避免只用年首/年尾两个瞬时值。
5. 本轮修复了 RDH 未知大小资产的陈旧临时文件冲突、`budget` 结果的 JSON 序列化和残差图键名/量纲错误。

## 解释边界

- 只有 2012、2015、2019 三个年份，不能当作连续三年气候序列，也不能做趋势推断。
- `Th` 的参照带来自全国年尺度文献量级，区域对流/层状云过程可能低于 1 h；因此报告保留告警，而不是修改阈值。
- 本报告报告的是 NCAR RDA 重分析切片和明确控制体内的计算结果，不替代站点观测或再分析产品间的不确定性评估。
